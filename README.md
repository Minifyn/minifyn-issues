# MiniFyn feedback and issues

Public tracker for all MiniFyn products: the minifyn.com website and short links, ScamGuard (app and browser extension), ClipFyn, CensorFyn and SendFyn.

## Open an issue

[New issue](https://github.com/Minifyn/minifyn-issues/issues/new/choose), then pick a form:

- **Bug report**: something doesn't work
- **Crash report**: the app closed unexpectedly (apps can pre-fill this)
- **Feature request**: an idea or improvement
- **ScamGuard wrong result**: a safe link flagged, or a scam missed
- **Translation problem**: wrong or unnatural text in your language
- **Accessibility problem**: screen reader, keyboard, text size, contrast
- **Question**: how something works
- **Report abusive short link**: phishing, malware or illegal content behind a short link

## Not here (private channels)

- **Security vulnerabilities**: [report privately](https://github.com/Minifyn/minifyn-issues/security/advisories/new). Never in a public issue.
- **Privacy and data requests**: see the [privacy policy](https://www.minifyn.com/privacy)
- **Billing and refunds**: [contact page](https://www.minifyn.com/contact)
- **Copyright notices**: [DMCA page](https://www.minifyn.com/dmca)

## Before you post

- Issues are public. Leave out personal data, files, passwords and private links.
- Write suspicious links with brackets so nobody clicks them: `hxxps://example[.]com`.
- Search existing issues first.
